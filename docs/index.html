01 · Host

Share this PC.

Two panels, two jobs. Start hosting, and invite a device with a code. No addresses, user names or passwords to read out.

  • Clean stop. Players are disconnected and their virtual gamepads unplugged before the server exits.
  • Ahead of games. Kyber's capture and encode get the highest GPU priority Windows allows.
  • Fastest encoder, measured. Each encoder and codec your graphics card offers is tried on this PC; the fastest one that shows a picture wins.

02 · Join

Type the code.

PCs running Godrays appear on their own. Pick one, type the six digits it shows, and you are paired: the sign-in is handed over and the host's certificate pinned, so nothing can pretend to be it.

  • Pad, keyboard or mouse. A number pad for the d-pad, digits straight from the keyboard.
  • SPAKE2 pairing. The code cannot be guessed from the network; three wrong tries burn it.
  • Leave any time. Hold Start + Back + LB + RB, press Ctrl + Alt + Shift + Q, or click Leave.

05 · Get going

Three steps.

Run it on both PCs

Download godrays.exe. On first start it offers to install Kyber (Windows asks for permission once).

Host and invite

On the PC with the games: Host, Start hosting, Show a code.

Join and play

On the other: Join, pick the host, type the code. Next time, one press.
